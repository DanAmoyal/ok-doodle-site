OK Doodle

A draw-and-guess game for friends, in development. One player draws a word, the other watches the drawing replay stroke by stroke and guesses it, then draws one back.

OK Doodle uploader

"OK Doodle uploader" is the developer's build tool. It copies test builds of the game to the developer's own Google Drive. It can only see and change files it created itself (the drive.file permission), and it is not offered to anyone else.
